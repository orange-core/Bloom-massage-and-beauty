# Bloom Massage & Beauty — Website Concept

A responsive, single-page website concept for Bloom Massage & Beauty, designed around a calm, editorial spa aesthetic.

## Preview locally
Open `index.html` in a browser. Google Fonts requires an internet connection; system serif/sans-serif fallbacks are included.

## Included
- Responsive layout and mobile navigation
- Treatment overview for massage, facials, eyebrow threading, and waxing
- Enquiry form that prepares/copies a message for the visitor
- Accessible form labels, reduced-motion support, and basic metadata

## Before publishing
This is a concept, not an official or verified business website. Confirm all business details with Bloom before launch:
- Official phone/WhatsApp number and social/contact links
- Address, opening hours, and appointment process
- Treatment names, descriptions, availability, and prices
- Permission to use real business photos and customer testimonials

No phone number, prices, location, opening hours, or testimonials have been invented. The enquiry form does not submit to a server and does not book appointments; it prepares text for the visitor to send through a confirmed official contact channel.

## Deploy
Can be hosted as a static site on GitHub Pages, Cloudflare Pages, or another static host once the business approves the content and contact flow.
